# 🎓 Telegram-бот для автоматической генерации рефератов (v2.1)

Бот для Telegram на базе **aiogram 3**, который автоматически генерирует структурированные рефераты на заданную тему и отправляет готовый документ в формате `.docx` (Microsoft Word) с академическим оформлением (шрифты Times New Roman, отступы, ГОСТ-структура, содержание и список литературы).

Для минимизации галлюцинаций бот предварительно выполняет поиск релевантных материалов в **DuckDuckGo** и **Википедии** с поддержкой нескольких языков.

---

## 🌟 Основные возможности

- 🌐 **Мультиязычность (3 языка):**
  - 🇰🇿 Қазақша
  - 🇷🇺 Русский
  - 🇬🇧 English
- 📑 **Гибкий выбор объёма:**
  - 5, 8, 10, 12, 15 или 20 страниц (автоматический пересчёт целевого числа символов).
- 📋 **Шаблоны оформления и структуры:**
  - **Стандартный реферат** — классическая структура (введение, 3–4 раздела, заключение, список литературы).
  - **Вузовский (ГОСТ)** — расширенная академическая структура с аннотацией, содержанием и ГОСТ-рубрикацией.
  - **Краткий доклад** — структурированные тезисы для устного выступления на семинарах и конференциях.
- 🔍 **Умный сбор контекста (RAG):**
  - Генерация мультиязычных поисковых запросов под выбранный язык.
  - Автоматический поиск актуальных сниппетов через DuckDuckGo.
  - Поиск и выжимка тематических статей в Википедии.
- 🤖 **Поддержка различных AI-провайдеров:**
  - Облачные провайдеры (DeepSeek с оптимизацией Prompt Caching, OpenAI, OpenRouter, Groq, RunPod).
  - Локальный запуск через **Ollama** (Qwen 2.5, Gemma 2, DeepSeek-R1 и др.).
- 📄 **Формирование документов `.docx`:**
  - Автоматическая трансляция Markdown-разметки в стили Word (заголовки Heading 1/2/3, отступы первой строки 1.25 см, межстрочный интервал 1.5, поля 2–3 см).
  - Автоматическая очистка временных файлов после отправки пользователю.

## 🚀 Установка и запуск

### 1. Клонирование репозитория и окружение

```bash
git clone https://github.com/erajunior891/referat-bot.git
cd referat-bot

# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Активация окружения (Linux / macOS)
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (`.env`)

Скопируйте файл примера `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните необходимые параметры в файле `.env`:

```ini
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz

# Провайдер нейросети: 'deepseek', 'ollama', 'openai', 'openrouter', 'groq'
LLM_PROVIDER=deepseek

# Настройки для Cloud API (DeepSeek / OpenAI)
API_KEY=sk-your-api-key-here
API_BASE_URL=https://api.deepseek.com
API_MODEL=deepseek-chat

# Настройки для локальной Ollama (если выбран LLM_PROVIDER=ollama)
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b

# Лимиты
NUM_PREDICT=4096
MAX_CONTEXT_CHARS=6000
REQUEST_TIMEOUT=300
```

### 3. Запуск бота

```bash
python main.py
```

## 💬 Сценарий взаимодействия с пользователем

1. Пользователь вводит команду `/start`.
2. Бот предлагает выбрать **язык реферата** (Қазақша / Русский / English).
3. Пользователь выбирает **объём реферата** (от 5 до 20 страниц).
4. Пользователь выбирает **шаблон оформления** (Стандартный / Вузовский / Доклад).
5. Пользователь вводит **тему реферата** текстом.
6. Пользователь отправляет свой **план** или нажимает «⏭ Пропустить» для автоматической генерации плана.
7. Бот информирует о статусах выполнения (поиск источников → подготовка промпта → генерация текста → сборка Word-файла).
8. Бот отправляет готовый файл `.docx` в чат.

```text
referat-bot/

│   ├── handlers.py          # Обработчики сообщений и FSM-диалога
│   ├── keyboards.py         # Инлайн-клавиатуры (язык, страницы, шаблоны, отмена)
│   └── states.py            # FSM-состояния конечного автомата
├── services/                # Бизнес-логика и сервисы
│   ├── ai_client.py         # Клиенты нейросетей (Ollama, DeepSeek, Cloud API)
│   ├── docx_generator.py    # Сборка документа Word (.docx) по ГОСТу
│   ├── orchestrator.py      # Оркестратор: поиск + AI + сборка документа
│   └── search.py            # Поиск в DuckDuckGo и Wikipedia
├── templates/               # Шаблоны промптов и документов
│   ├── prompts/             # Текстовые промпты для разных типов рефератов
│   └── registry.py          # Реестр метаданных шаблонов
├── config.py                # Загрузка и валидация конфигурации (.env)
├── main.py                  # Точка входа приложения
├── requirements.txt         # Зависимости Python
└── README.md                # Документация проекта
```

## 🛡️ Безопасность и отказоустойчивость

- **Предотвращение флуда:** защита от повторного запуска генерации одним и тем же пользователем до завершения активной задачи (`_active_users`).
- **Безопасная очистка:** автоматическое удаление сгенерированных `.docx` из временной папки `temp/` в блоке `finally` даже при сбоях отправки.
- **Поддержка команды `/cancel`:** возможность прервать ввод данных на любом шаге диалога.
